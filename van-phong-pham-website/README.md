# Website Cửa Hàng Văn Phòng Phẩm

Website giới thiệu **sản phẩm văn phòng phẩm** và hỗ trợ *quản lý đơn bán*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| `docs` | Tệp nhập hàng và tài liệu dự án |
| `media` | Logo cửa hàng |
| `data` | Bảng tính đơn bán tháng 10 |
| `logs` | Log cửa hàng và các báo cáo |
| `backup` | Bản sao dự phòng của logo |

## Xem nội dung dự án

```powershell
Get-ChildItem -Recurse -Force
```

## Công việc

- [x] Sắp xếp các tệp vào đúng thư mục
- [x] Hoàn thiện bảng tính đơn bán tháng 10

> Không upload file `.env` lên GitHub.
